# Swarna Nishmitha — Portfolio

A responsive personal portfolio built with HTML, CSS, and Bootstrap 5.

## Run locally

Open `index.html` in a browser.

## Deploy with Netlify

This is a static site. To deploy it with Netlify, import `nishmithaswarna/personal-portfolio` from GitHub and use the settings in `netlify.toml`. Netlify will publish the repository root, and subsequent pushes to `main` will trigger a new deploy.

The resume button expects the PDF at `assets/resume.pdf`.
