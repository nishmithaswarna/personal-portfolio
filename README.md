# Swarna Nishmitha — Portfolio

A responsive personal portfolio built with HTML, CSS, and Bootstrap 5.

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site whenever changes are pushed to `main`.

Before the first deployment, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**. The repository owner must enable Pages once; workflow permissions cannot enable it automatically. After that, pushes to `main` deploy the site, and the published URL appears in the workflow deployment details.

The resume button expects the PDF at `assets/resume.pdf`.
