# Swarna Nishmitha — Portfolio

A responsive personal portfolio built with HTML, CSS, and Bootstrap 5.

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

The workflow in `.github/workflows/pages.yml` enables GitHub Pages and deploys the site whenever changes are pushed to `main`.

If repository or organization policy prevents the workflow from enabling Pages, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**. After a successful workflow run, the published site URL will appear in the workflow deployment details.

The resume button expects the PDF at `assets/resume.pdf`.
